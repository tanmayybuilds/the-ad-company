# The Ad Company — version 5 homepage

Lovable's exported components and artwork, completed against the approved Stitch design. Original exports remain untouched in Downloads.

Stack: React 19, TypeScript, Vite 8, Tailwind CSS 4, GSAP + ScrollTrigger, Three.js + React Three Fiber. Static output is hosted on GitHub Pages at https://tanmayybuilds.github.io/the-ad-company/. The blank TanStack Start shell was replaced with a Vite entry point; this site currently needs no server rendering or server secrets.

Commands: `npm install`, `npm run dev`, `npm test`, `npm run build`.

Typography uses only the eight selected families: Outfit, General Sans, Satoshi, RX100, Rajdhani, Sora, Zodiak and Kalam. Original WOFF2 files and supplied licenses are local; only the heading and body faces are preloaded. Font roles and sources are documented in [typography](docs/typography.md).

Residential journey prototype: open `/?prototype=residential#services` on the local server. This opt-in route replaces only Services with five live 3D placements: gate branding, lift screen, doorstep leaflet, flyer handoff and community activation. Scroll controls the camera, people and vehicles; in-scene buttons jump to readable holds. The actual company logo is shared across all advertising surfaces. The paused GSAP timeline follows Hyperframes' deterministic authoring approach; no MP4 or additional player runtime is needed. The renderer lazy-loads near the section, uses demand rendering, pauses offscreen, and retains an SVG still preview with working controls for reduced motion or WebGL failure. See [prototype design](docs/superpowers/specs/2026-10-28-residential-journey-design.md). The user is handling visual testing; GPU performance and rendered appearance have not been measured.

V4 uses the client-approved Porcelain & Teal palette across the interface: porcelain `#F7F9F8`, pale teal `#E5EFF0`, logo teal `#12546B`, gold `#D9A328`, and dark text `#102F38`. The palette is fixed in `src/styles.css`; there is no theme picker or stored theme preference. Dark feature sections use deeper teal shades with readable gold accents. Existing client marks, photos, and videos keep their original colors.

The supplied transparent logo is retained in `public/brand/logo.png`. Its SVG wrapper embeds the original PNG pixels and trims only empty margins. Header, footer, campaign preview, site icon, and 3D signs use the artwork directly over their existing backgrounds, without a white backing.

Editable business content is in `src/content/site.ts`. Shared motion settings live in `src/lib/motion.ts`. Version 5 on `home-page` replaces the active WebGL hero with a CSS campaign collage. The opening is a full-screen scatter of 25 letters and six visible artwork panels on the teal-and-gold street-map canvas. On landing, a 400ms pause shows the scatter before one eased entrance assembles the actual elements in roughly two seconds. The completed homepage stays in place. The hero creates no scroll pin, spacer, snap or scroll listener; ordinary page scrolling is always available. Resizing across desktop/mobile breakpoints does not replay the entrance. Reduced-motion users receive the completed static hero immediately. All retained imagery is local.

Hero panel images are editable in `hero.panels` in `src/content/site.ts`. Five `image: null` entries show intentional artwork placeholders; replace a null with a local `/...` image path to add campaign imagery. The outdoor panel uses the supplied illustrative billboard. The hero loads no videos or live 3D scene. One assembly timeline owns the transforms, and motion-preference changes clean up that timeline. All other homepage sections and the second work video's three-second trim are retained.

The team camera uses a centered close-up with a 14-degree tilt, larger pedestals and portraits, and readable active profile cards. Three stops render at rest; travel briefly retains the outgoing stop while preparing the arriving pointer and its next two stops, with at most four visible. Upcoming portraits are decoded ahead of arrival, and decorative effects stay still when idle. Services uses a paused native video, with scrolling as its only playback clock. It prepares near the viewport and keeps the browser's buffer when visitors scroll away and back.

Services uses all five supplied videos in order: residential/community, corporate/coworking, outdoor/transit, cinema/airports/in-flight, delivery/in-app. All 1,197 original video frames and four 18-frame eased dissolves are retained in a fast-start H.264 file: 8.7 MB desktop, 4.3 MB mobile, replacing 52.5 MB across 1,269 separate image requests. Scroll drives both directions; category buttons seek each clip's start. Slow seeks finish before the latest target is requested, avoiding repeated cancellation. Reduced motion uses only selectable still previews. The original frames are retained for preparation and recoverability; the live section requests only its category posters. Work cards initially load three posters totalling 50 KB; their videos load on interaction and total 2.8 MB instead of 78.6 MB. See [media preparation and checks](docs/service-video-sequence.md).

Within the team tour, one scroll gesture moves one pointer forward or backward and settles exactly there. At pointer 01 upward scrolling exits; at pointer 05 downward scrolling exits. The counter, next-button boundary and scroll distance follow the roster length. Once the whole section has left the screen, returning upward skips its animation distance and resets the tour. A later downward visit starts again at pointer 01.

Services scrolls forward and backward within the animation during an active visit. This remains available just after the pin releases while the stage is still visible. Once the entire stage has scrolled above the header, returning upward bypasses the animation distance and resets it; a fresh downward visit can scrub both ways again.

Manual Services selection uses a single 450 ms frame transition with the category highlight held on the chosen destination. Its document position aligns immediately, rapid clicks replace the previous transition, and new scroll input settles the interrupted transition before resuming normal scrubbing.

Reverse exits require actual upward input, so rounding, pin refreshes and manual pointer navigation cannot reset a forward journey. Services scrolls naturally when its panel cannot fit the viewport, and Services/Coverage omit long pins under reduced motion. See the [showcase code audit](docs/showcase-audit.md) for fixes, verification and remaining business handoff items.

Deployment: run `npm ci`, `npm test` and `npm run build`, then commit the contents of `dist/` to the existing `gh-pages` branch without rewriting its history. GitHub Pages publishes that branch's root. Keep `.nojekyll` in the output. Vite's relative base and base-aware client image URLs support the repository subdirectory. Verify the live page after refreshing any older cached bundle, including all 16 logos.

Publish only when the user explicitly requests it. Do not deploy to Sites; `.openai/hosting.json` is retained solely as the earlier hosting identity. Never store GitHub tokens in repository files, remote URLs or Git configuration. The current site retains noindex and disallows crawlers while campaign content and enquiry delivery are unfinished.
